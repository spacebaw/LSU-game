## 1. Purpose and public surface

The only DOM owner. Builds the whole HUD inside `#app` once in `init`, refreshes it in `update(state, dtMs)` with diffing, translates every pointer/wheel/key event through one input state machine, and exposes the notification/card/toast/inspect/palette APIs every other module uses. It writes sim state **only** through action functions. `ui_panels.js` extends this object with the panels, cards and the debug panel.

Copy the API from ARCHITECTURE §7.2 verbatim (`init, reset, update, notify, ticker, openPanel, panel, inspect, closeInspect, card, decision, selectTool, tool, setOverlay, setSpeed, showTitle, hint, pointer, keydown, wheel, breakdown, refreshPalette, settings, saveSettings`). Additions:

```js
BSU.ui.answerDecision(id, answer) → void      // idempotent; resolves the open toast with 'yes'|'no'|'default'; owners call it at their tick-based timeout
BSU.ui.closeCard(id?) → void                  // closes the current modal card (or a specific one)
BSU.ui.el                                     // {app, world, hud, topbar, …} every node ui created, by id-ish key (never re-queried)
BSU.ui.hoverTile → number|-1                  // set on pointermove; render_fx reads it (render.hoverTile mirror: ui writes BSU.render.hoverTile = i)
BSU.ui.debug → {hydroNumbers: boolean, perfHud: boolean, open: boolean}   // render/panels read
BSU.ui.state → 'IDLE'|'PANNING'|'PLACING'|'DRAGGING'|'INSPECTING'        // the machine state (tests)
BSU.ui.registerPanel(name, {build, refresh, events: string[]}) → void       // ui_panels registers at definition time (plain registry)
BSU.ui.registerCard(id, builder) → void                                     // ui_panels registers card builders
BSU.ui.alert(state, spec|null) → void         // the alert strip: {icon, text, action?: {label, fn}, gator?: {name, i}}
BSU.ui.fmt = {money: BSU.formatMoney, date: BSU.formatDate}
BSU.ui.cards → Object<string, builder>        // the card builders registered by ui_panels (builder(state, payload) → card spec)
BSU.ui._tests = []                            // ui_panels pushes test functions; ui.selfTest runs them
BSU.ui.introduceTab(state, tab) → void        // progress: tabsIntroduced[tab] = true (+ a pip) and a palette refresh
BSU.ui.lockTool(on) → void                    // Objective 1: the Founders' ghost cannot be cancelled until placed
```
During the charter swoop (`progress.tutorialStage() === 1`) any pointerdown/keydown calls `progress.skipSwoop(state)`.

Module shape: `'use strict'` IIFE; `const M = (BSU.ui = BSU.ui || {})`; `init/reset(state, fresh)/update/selfTest`; **no DOM at definition time** (`registerPanel/registerCard` are plain map writes). `reset` behaves the same for both `fresh` values (close panels/cards/inspect, tool null, palette refresh from `buildings.unlocked` — which self-heals on the new root even though `progress.reset` runs later, §1). No state on the module object (D46): `M.el`, `M.debug`, `M.state` are ui-private DOM/machine bookkeeping, never mirrors of `state.*`.

## 2. State fields

**Writes (owner):** `state.ui.overlay`, `speed` (through `session.setSpeed` — the write itself is session's), `speedBefore` (session), `tool` (unsaved), `panel` (unsaved), `paletteTab`, `tabsSeen`, `newPips`, `tabsIntroduced` (progress sets these during the tutorial through `ui.introduceTab(tab)` — add it), `settings` (mirrored to `localStorage['bsu.settings']`), `state.progress.hints` only via `progress.markHint(state, id)` (add to progress; ui reads the flag as `state.progress.hints[id]`, never `BSU.progress.hints`). Never `ui.camera` (render's).

**Reads:** everything, read-only, through the owners' query functions; the DOM diff reads `state.economy.*` (cash/students/prestige/happiness/ecology), `calendar`, `sky`, `weather.heat/riverStage/storm/cone`, `storms.current`, `progress.objective()/nearestMilestones()/recap()`, `state.ticker`, `buildings.*` (`buildings.unlocked(state, id).reason` for the palette condition text), `wildlife.onCampus()` and `state.wildlife.leGrand` (a state field, not a module property), `state.sports.game` (the score bug; never a `sports.game()` call), `hydro.*` for the inspect panel, `agents.inspect/nearest`, `sports.season()`.

## 3. Events

**Emits:** `ui:notify{text, kind, action?, showMe?, ttl?}` (from `notify`; the `onClose` callback is not part of the payload), `ui:panel{panel}`, `ui:overlay{overlay}`, `ui:tool{tool}`, `decision:open{id}` / `decision:closed{id, answer}`.

**Listens (owner `'ui'`):** `econ:stat` (odometer/delta flash), `econ:income/expense` (nothing; render_fx), `enroll:*`/`agent:arrive` (the Students odometer rolls on `agent:arrive`; the chip updates on `econ:stat`), `objective:offered/complete/dismissed/progress` (card refresh; sparkle), `milestone:earned` (toast with the tiger-paw stamp + `notify`), `unlock:changed{ids}` (palette refresh + pips), `storm:named/watch/bands/landfall/passed` (alert strip, `#btn-storm` dot, newsflash card), `storm:toast{id, text, yes, no, untilTick}` (→ `decision`), `storm:report{report}` (→ the damage-report card via `ui_panels`), `mosquito:warning` (alert + notify with Show me), `gator:campus{enter, name, i}` (the gator chip), `weather:heat{advisory, wave}` (weather chip orange), `power:blackout/restored` (alert), `building:flooded` (alert "flood", first-time notification with Show me is progress's), `festival:start/end`, `game:*` (score bug via panels; kickoff notify), `board:offered`/`voice:offered`/`econ:card` (cards via panels), `ui:ticker` (ticker refresh), `save:written/loaded` (notify 'Saved' / close title), `speed:changed` (buttons), `setpiece:start/end` (Skip button visibility; hide the palette during set pieces), `error{first}` (a red perf-chip counter in debug), `sky:phase` (the sky glyph), `calendar:day` (date text — cheap to diff every frame anyway), `ring:changed` (Objective 11 card line refresh), `coverage:changed` (icons; inspect refresh), `camera:moved` (minimap viewport rect).

Listeners mark dirty flags; DOM writes happen in `update`.

## 5. Edge cases and invariants

- `update` ≤ 1 ms: diff every text (`if (el.textContent !== s) el.textContent = s`), toggle classes only on change, never rebuild lists per frame (palette rebuilt on `unlock:changed`; inspect on 500 ms; panels on their own cadence).
- Every section of `update` in try/catch (`BSU.error('ui', 'update:<section>', e)`).
- Never mutate sim state directly; every action goes through an action function and shows the returned `reason` on failure (`notify` or the ghost label).
- The stub: `getBoundingClientRect` returns the element's `width/height`; `#world` is 1280×720 in tests; `document.getElementById` works only for `#app` and ids assigned through `.id =` (the stub tracks those) — still keep references.
- Set pieces: hide the palette and the tool (cancel to IDLE), show the Skip button when `setPiece.skippable && tick ≥ skipAfterTick (150)` (`session.skipSetPiece`), keep panning/zooming live.
- Title shown: no HUD updates except the title (cheap).
- Load (`reset`): close panels/cards/inspect, tool null, palette refresh, alert cleared, notifications cleared, `showTitle(false)` is session's call.
- A decision toast and a card never overlap: the toast is above cards in z-order and takes the keys first.
- Localization: none; all strings from `data` or the GDD wording.
- `#ghost-label` and `#tooltip` never overflow the viewport (clamp to `vw − width`).

## 6. selfTest() requirements

Pure; no DOM writes (the machine is tested through a private instance or by calling `pointer()` in a "dry" mode: expose `M._machine(state)` returning a transition function over `{state, event}` that uses injected callbacks — test the transitions without the DOM):

1. `data.keys` has no duplicate `(key, ctrl, shift)`; every key in the ARCHITECTURE §7.4 list is present; `q` is absent; digits `1 2 3` map only to speeds.
2. Machine transitions on synthetic events: IDLE + down(left) → armed; armed + move 3 px → armed; + move 6 px → PANNING; PANNING + up → IDLE; armed + up (hit a tile) → INSPECTING; INSPECTING + Esc → IDLE; IDLE + selectTool('dorm') → PLACING; PLACING + Esc → IDLE; PLACING(drag row) + down → DRAGGING; DRAGGING + move → run grows 4-connected (no diagonal steps); DRAGGING + up → PLACING; PLACING + right-click(≤ 4 px) → IDLE; PLACING + `r` on a rotatable row toggles `rot`.
3. Straight-line run with Shift from (10,10) to (14,12) → all tiles on `ty 10` (the larger delta axis is x).
4. `Esc` layer order: with a tool + inspect + panel + card all open, four presses close them in the order tool → inspect → panel → card.
5. Decision toast: `decision(s, {id:'t', ticks: 80})` then `answerDecision('t','yes')` emits (through the recorder) exactly one `decision:closed{id:'t', answer:'yes'}` and calls the optional `onAnswer` once; a second `answerDecision` is ignored (still one event); a fresh toast with `state.tick` advanced by 80 resolves with `'default'` in `update`.
6. Precedence: with a toast open, `keydown('y')` answers and returns true; with a focused input, `keydown('b')` returns false (not handled); with a card open, `Enter` fires its primary action.
7. `formatMoney` usage: the cash label for 4,120,000 is `$4.12M`, for 340,000 `$340k`, for −1,400,000 `−$1.4M`.
8. Palette visibility rule: a tab with zero unlocked rows is hidden even when introduced; `essentials` shown once introduced.
9. Stub-safe skeleton: after `init` on the stub, every `#id` listed in ARCHITECTURE §7.1 resolves through `M.el` (not through the DOM), and no created element is referenced only through `innerHTML`.
10. `card(s, 'nope')` opens nothing and reports one `BSU.error`; `card(s, {id:'x', title:'t', body:'b', actions:[]})` queues one card.
11. `keydown('`', mods)` and `keydown('Dead', {…, code:'Backquote'})` both toggle the debug panel; `keydown('Backquote', {…, code:'Backquote'})` too.

`selfTest` emits nothing on the live bus: `decision:*`/`ui:*` go through `M._deps.emit`, replaced by a recorder for the duration (§10.6); assertions with `BSU.assert` (the harness sets `BSU.SELFTEST`).
