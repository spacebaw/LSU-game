The story engine: the tutorial script, the 25-objective chain with the interrupt/background scheduler, milestones, the timer table, Student Voice cards, Board cards, failure states and the receiver autopilot, the Founders' Day recap, unlock rules (the single source), the ticker, first-warning speed drops, the scripted cells, Amélie/Célestine gating, the first gator, the scripted night game, the parade and graduation set pieces. ## 2. State fields

**Writes (owner):** `state.progress.*` (all of §2.9), `state.ticker[]` (≤ 30, newest last). Via action functions only: `economy.post/bump/addStudents/applyCard/setAutoRepair`, `weather.queueCell/suppressRainOn/scheduleNearMiss/setRunning`, `wildlife.forceFirstGator`, `hydro.forceSat`, `session.startSetPiece/setSpeed/restoreSpeed/skipSetPiece`, `ui.selectTool/lockTool/introduceTab/notify/card/hint/decision/openPanel`, `render.panToTile/flashTiles/particles.emit`, `buildings.place/placeRun/repairAll/clearBoilWater/rename`, `sports.startNightGameScript/postpone`, `agents.spawnArrival/launchCajunNavy`, `audio.play`.

**Reads:** everything, read-only, through query functions.

Private (closure, rebuilt in `reset`): event queues (`pendingEvents[]` — every listener pushes `{name, payload}`; `tick` drains it), the objective trigger table, the milestone condition table, parade state, `lastTickerDay`. `M._deps = {emit: (name, payload) => BSU.events.emit(name, payload)}` — **every emit in this module goes through `M._deps.emit`** so `selfTest` can swap in a recorder (§10.6). `reset(state, fresh)`: on both `fresh` values lazily initialize the saved keys contract.js lacks — `state.progress.forceFirefliesDay ??= -1`, `state.progress.drainedEver ??= false`, `state.progress.failure.pendingKind ??= null`; when `fresh === true` also fill `voiceCards` from `data.voiceCards`; when `fresh === false` derive nothing (everything is saved). `unlocked/unlockOk/unlockReason/earned/timer/timers/offered` are pure over their `state` argument (any cache is keyed `cacheRoot === state`, §1) because `ui.reset` queries them before `progress.reset` has run on a new root.

## 3. Events

**Emits:** `objective:offered/complete/dismissed/progress{id, kind, text, progress?, goal?}`; `milestone:earned{id, name, reward}`; `timer:added/expired{id, value, untilDay}`; `unlock:changed{ids}`; `board:offered{cards}` / `board:resolved{chosen}`; `voice:offered{id, student, text}` / `voice:resolved{id, state}`; `ui:ticker{text, kind, subject}` (from `ticker()`).

**Listens (owner `'progress'`; every listener only pushes to `pendingEvents`):** `building:placed/complete/removed/flooded/dried/damaged`, `tile:changed` (Objective 4/11 live checks are polled in `tick`, not per event — subscribe only to set `ringDirty`), `ring:changed`, `enroll:round/lock/graduation`, `agent:arrive`, `agent:desireLine`, `gator:campus/incident/relocated`, `mosquito:warning`, `ecology:changed`, `weather:cell`, `storm:named/watch/bands/landfall/report/passed`, `surge:*` (no), `levee:burrow/overtop/breach`, `game:kickoff/final`, `season:end`, `econ:card/income/month/stat`, `festival:start/end`, `calendar:date/day/month/year`, `decision:closed`, `setpiece:end`, `power:blackout`, `save:loaded` (→ nothing; `reset` handles), `marsh:drained` (L2 Untouched tracking), `sky:phase` (Dusk triggers: first gator, parade start).

## 5. Edge cases and invariants

- Never act inside a listener; drain `pendingEvents` in `tick` in arrival order; at most one `objective:offered` per tick.
- Every objective id exists in `data.objectives` (+ `v:<voice id>` and `p1..p3` synthesized); unknown ids in the queues are dropped with `BSU.error`.
- Rewards paid exactly once (`state === 'done'` guard); grants only for 1–7, 9, 10, 11.
- Set pieces started by progress only when `state.setPiece === null`; if another set piece is running, defer to the next tick (a parade never overlaps a landfall: weather's schedule avoids Feb 8 by 6 days, but a forced storm could — defer).
- Timers: `untilDay` is `-1` (open-ended) or a finite absolute day; never `Infinity` or NaN; `value` finite. No field of `state.progress` (or anything progress writes) may ever be non-finite (§10.3).
- `skipTutorial`: no scripted beats except the Apr 5 cell, Amélie, Célestine, the first gator (it is a calendar event — yes, it still fires), first-warning drops off.
- Headless: identical; `ui.*` calls run against the stub; `render.*` calls are no-ops.
- Load (`reset(state, false)`): rebuild the trigger table, lazily initialize the missing saved keys, derive nothing else (all saved); `pendingEvents` empty. `reset(state, true)`: additionally fill the voice deck. Never draw `rng.sim` in `reset`.
- Receiver autopilot never leaves the game unplayable: the palette is disabled but panels open; `[Skip Year]` ends it.
- Determinism: fillers and draws via `rng.sim`.

## 6. selfTest() requirements

To feed the date handlers, call the exported `M._onDate(state, 'Jun 1', day)` (the `calendar:date` handler) directly instead of emitting.

1. Objective graph: every trigger references existing ids; no orphan (every id except `'1'` has a trigger); the interrupt/background kinds match `data.objectives`; rewards: grants exactly for `{1..7, 9, 10, 11}`.
