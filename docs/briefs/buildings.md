## 1. Purpose and public surface

Everything that is a Building struct or a drag tile written by the player: validation, cost, placement, construction, coverage (⚡💧), the protection flood-fill and gap detector, damage/repair/ruin/tarps, pilings, re-grade, tiers, policies, board-up, sandbags, shelter, auto-names, undo, demolish. It is the **only writer** of `buildings[]`, `tiles.owner`, `tiles.crest`, `tiles.integrity` (placement/repair), `tiles.sandbag` (write 15), `runNames`. It writes `surface` and `elev` only through `terrain.setSurface/setElev`, and canal/pond/levee hydro flags only through `hydro.markCanal/markPond/markLeveeChange`.

Copy the full API from ARCHITECTURE §5.6 verbatim (`canPlace`, `place`, `placeRun`, `remove`, `undo`, `list`, `get`, `at`, `count`, `has`, `footprint`, `coverage`, `auras`, `recomputeCoverage`, `protection`, `gaps`, `ringClosed`, `coveTilesUnreached`, `boundaryLevees`, `repair`, `repairAll`, `repairLevee`, `repairAllLevees`, `retrofitPilings`, `regrade`, `rename`, `upgrade`, `setPolicy`, `refuel`, `boardUp`, `sandbags`, `applyWindPulse`, `applySubsidence`, `onIntegrityChanged`, `damageReport`, `shelter`, `stats`, `upkeepTotal`, `leveeRuns`, `dumpsterTile`, `unlocked`, `constructionMult`, `effective`, `dirtyRing`). Additions this brief makes (other briefs reference them):

```js
BSU.buildings.shelterOverflow(state) → void            // landfall shelter toast 'yes': Dining Hall closedUntil = day + 3; storm.shelterOverflow = true (weather passes the storm)
BSU.buildings.shelterAssignments(state) → Object<number, number>   // {buildingId: capacity} of every usable shelter (complete, unflooded, effective > 0; capacities exactly as shelter() counts them). Weather passes this map UNCHANGED to agents.shelter(state, capacities); agents does the per-agent greedy assignment itself (D41). Never an agentId → buildingId map
BSU.buildings.gatorClosed(state, id) → boolean          // a gator within 2 tiles of the footprint this tick (transient, from wildlife.onCampus())
BSU.buildings.boilWaterTriggered(state) → boolean       // tracked from landfall to T+1 (tower flooded or unpowered at any tick); progress reads at T+1 and resets
BSU.buildings.placeOpts                                  // documented opts: {rot, pilings, grade, tiles, ignoreCash, instant}
```

`place(..., {instant: true})` sets `built = 1`, `builtDay = day` (skipTutorial's Founders' Hall).

## 3. Events

**Emits:** `building:placed{id,type,tx,ty,w,h,cost,pilings}`; `building:removed{id,type,tx,ty,w,h,refund,reason}`; `building:complete{id,type,tier?}`; `building:upgraded{id,type,tier}`; `building:damaged{id,type,hp,cause}`; `building:repaired{id,cost}`; `building:renamed{id,name}`; `power:blackout/restored{provider,affected,cause}`; `coverage:changed{}`; `ring:changed{H,closed,gaps}` (for H = 5 or the forecast height when it is recomputed after a dirty); `tile:changed` only via `terrain.touch` (never emit it directly).

**Listens (owner `'buildings'`):** `storm:pulse{n,share}` → push to `pendingPulses` (applied in `tick`); `storm:phase{WALL}` → read `storm.rolls` for the substation outage/fence break/azalea shred at the next tick; `storm:phase{LANDFALL}` (pulse 2 is where the tower roll plays: apply at tick 380 = pulse 2); `building:flooded/dried` → `coverageDirty = true` (a provider flooded), boil-water tracking; `levee:overtop/breach/burrow` → `dirtyRing`; `tile:changed{what:'crest'|'flags'|'elev'}` → `dirtyRing`, `aurasDirty`? (auras depend on buildings, not tiles); `gate:closed/opened` → nothing (static test ignores live state); `calendar:day` not used (flags).

- [ ] 2 In bounds: `BSU.footprintTiles(tx, ty, w, h)` non-null (rotation swaps `w,h` when `rot === 1` and `rotatable`). Reason `'Off the map'`.
- [ ] 3 Terrain rule by `placeRule`: `LAND` — every tile is land (not OPEN_WATER/BAYOU/POND) and not MOUND; `PATH` — land incl. Marsh, not PRESERVE, `surface` not already 1 (re-laying is a no-op skip), not canal? (a path over a canal makes a culvert: **allowed**), not a mound; `ROAD` — land, not Marsh, not Preserve, **or** a water tile if the run forms a bridge ≤ 3 tiles (`bridgeMaxSpan`: the water tiles in the run between two land tiles ≤ 3; a single-tile `place` on water is allowed only if it extends an existing bridge or touches land on the far side — evaluate with `opts.tiles` for drags; reason `'Use a Boardwalk or a bridge'` on Marsh/Preserve, `'Bridges span 3 tiles at most'`); `BOARDWALK` — anywhere except a footprint tile and a mound; `LEVEE` — land incl. Marsh (not water, not Preserve? Marsh, not Preserve, not a footprint, not a mound (a canal on a levee tile → floodgate); `FENCE` — any land incl. Azaleas: Cat 3+ → every azalea veg `stage = 0` with `plantedDay = day` (regrows over 30 days: terrain advances stage 0→1 at +30 for azaleas — tell terrain: azalea stages 0→1 at +30 days, 1→2 at +60; write this in terrain's veg growth as a per-type table `{oak:[120,240], cypress:[120,240], palmetto:[60,120], azalea:[30,60]}`). Live Oaks at Cat 4+: each `chance(.02)` → `terrain.removeVeg`.
- [ ] Boil-water tracking: from `storm:landfall` to `lastLandfallDay + 1`: if any Water Tower is flooded or unpowered at any daily check (and every tick of the set piece: check at each `storm:phase`) → `boilWaterFlag = true`; `boilWaterTriggered()` returns it; progress adds the `boilWater` timer at T+1 and calls `buildings.clearBoilWater(state)`.
- [ ] Coverage (`recomputeCoverage`, §4.11, C19): providers = complete, not flooded, not `closedUntil ≥ day`, `hp > 0` substations (capacity 40, ×… summer draw ×1.5 → capacity `floor(40/1.5) = 26` in months 6–9 (decision: "summer draw ×1.5" reduces effective capacity)) and water towers (50; **25 if the tower is unpowered**: compute power first, then water); consumers = complete buildings whose row has `needsPower`/`needsWater`; for each consumer, providers in range (`Chebyshev(nearest footprint tiles) ≤ radius`) with spare capacity, nearest first, ties by provider id ascending; assign → `provider.power/water`, `powered/watered`. Generators: a consumer whose assigned substation is absent/blacked out but which lies within 6 of a generator with `fuelDays > 0` and `effective > 0` counts as `powered` (the generator "covers"). `blackout` = the consumer had a provider that is now flooded/outed/fuel-dry (vs. never had one). Emit `power:blackout{provider, affected, cause}` for each provider transitioning to out, `power:restored` on recovery, `coverage:changed` always. Recompute when `coverageDirty` (set by place/remove/complete, provider flood/dry, fuel change, outage start/expiry, summer boundary).
- [ ] `effective(state, id)`: 0 if `built < 1`, `ruin`, `flooded`, `closedUntil ≥ day`, `gatorClosed`; else if `economy.suppressCoverage` → 1; else `needsPower && !powered` and `needsWater && !watered` → 0; one missing → .5; else 1. Rows needing neither → 1. Pumps: `needsPower` → 0 or 1 (never .5: for pumps, treat "one missing" as 0 — they only need power). Brownout (a provider over capacity — cannot happen with the assignment rule; a brownout is when consumers **wanted** a provider but none had capacity): `stats().brownout = uncoveredConsumers > 0 && providersExist`; economy adds the `brownout` timer while true.
- [ ] Auras (`auras()`): rebuild when `aurasDirty`: `life` = max over Union/Rec/Greek/Po'boy/Dining/Habitat auras (`happiness.value × effective` within radius; Quad stacks to 6 → `green`), `green` = Σ Quad (cap 6) + Oak (veg stage ≥ 1: +1 within 4) + Azalea (+1 within 3, +2 in bloom Mar 1–Apr 10) + Pond + Rookery (cap 10 applied by economy), `dining` (1 within any effective dining radius), `shade` (oak: 1 − Π(1 − .3) per oak within 3, cap .9), `heat` (rec center .5 within 10 → store the multiplier, default 1), `mosq` (not used — wildlife computes sinks itself; leave zeros), `noise` (road-adjacent dorm tiles etc. are economy's abstract terms; leave zeros). `coverage(kind, tx, ty)` reads these.
- [ ] `stats()`: `beds` (Σ `beds × effective`), `seats`, `feeds`, `diningCovered` (share of housing footprint tiles inside an effective dining radius), `landmarks` (Σ landmark incl. tiers, + Mounds when reached (`terrain` plot mounds 4-adjacent to a surface 1–3 tile), + BSU West), `oaks` (veg oaks + quads), `cypress`, `stockedPonds`, `posts`, `quality` (bed-weighted mean housing quality), `lots`, `unrepaired` (hp < 1 count), `floodedCore` (any core building flooded > 3 days: `floodedSince ≤ day − 3`), `powerRadiusHits`, `generatorsRunning`, `brownout`, `pumpsRunning` (from `hydro.pumpRunning`), `shelter` (below), `academicFlags {library, engineering, coastal}`, `roadAdjacentDorms`, `pumpsNearDorms`, `barriersNearDorms`, `floodwallDormsNoOak`, `wastewaterPlants`, `parkingLots`, `bridges` (count of `surface === 2` tiles on water-flag tiles; economy's Second Campus check), `buildingValue` (Σ `row.cost` (+ tier costs) over complete buildings; economy's insurance base). Economy reads this once per day (cache the object per `(root, calendar.day)` — the cache self-heals when `cacheRoot !== state` so `wildlife.reset` may call it on a fresh root before `buildings.reset` ran; `stats()` is also called by ui/progress).
- [ ] `upkeepTotal()`: Σ complete footprint upkeep (`tiers[tier−1].upkeep` for tiered; `× 1.05` on pilings; Wildlife Post `× .5` with `progress.timer('postUpkeepHalf')`) + per-tile: road 100, boardwalk 150, fence 80, levee 400, floodwall 900, canal 500 + azalea veg 100 each. Pump running (`+$3k`, ×2 preDrain) and generator running (`+$2k/day`) are separate lines economy adds from `stats()`.
- [ ] Shelter (`shelter()`, §4.11): capacity = Founders' 300 (600 while a cone exists → `weather.storm()` non-null and phase ≤ LANDFALL + 1 day), Library 800, Engineering 800, Union 2000, Rec 1000, Stadium by tier (5000/15000/25000), + dorms/towers whose every footprint tile has `elev ≥ 5.0` or `pilings` (300/900 each, capped at their residents), + 600 if `storm.shelterOverflow`; only complete, unflooded, `effective > 0` buildings; `students = economy.students` (0 if evacuated); `ok = capacity ≥ students`; `lines` = the panel's text per building.
- [ ] Protection/gaps/ring (§6.2 Rings): `protection(H)`: BFS 4-connected from every OPEN_WATER tile, every BAYOU tile except those upstream of a **closed** barrier (barrier exists and `state.hydro.barrierClosed` — the state field, never a module property… the static test: "except Bayou tiles upstream of a closed Surge Barrier" — use: barrier exists → upstream excluded, since it will be closed when the surge comes; decision), and every map-edge tile; passes through tiles with `effectiveHead ≤ H` where `effectiveHead = elev + crest × integrityFactor + sandbag/10`, `crest` in full for a FLOODGATE with integrity ≥ 50, `crest = 0` for JAMMED tiles. Cache per `H` in `ringCache` (cleared by `dirtyRing`). `gaps(H)`: runs of reached tiles adjacent to an unreached tile and within 12 of any `crest > 0` tile → `{tiles, len, cx, cy, name}` named by the nearest of: cove mouth (`plot.mouth[1]`), south shoulder (`(bank0−9, 14)`), north shoulder (`(bank0−9, 5)`), bayou bank (nearest `plot.bayou` tile), river bank (`bank(ty)` column), chenier (`plot.cheniers[].cx,cy`), else `'(x, y)'`; `weak` = boundary levee tiles with integrity < 70; `gates` = FLOODGATE tiles on the boundary `{i, jammed}` (informational: "canal crossing at (x, y): will auto-close"); `reachedBuildings` = `{id, depth: H − elev_min}` for buildings with any reached tile. `ringClosed(H)`: every core building (Founders' + every `needsPower` row) unreached. `coveTilesUnreached(H)`: every `plot.cove` tile unreached. `boundaryLevees(H)`: levee/floodwall tiles with a reached 4-neighbor and an unreached 4-neighbor, or that are themselves reached with an unreached neighbor.
- [ ] Emit `ring:changed{H:5, closed, gaps: gaps.length}` after a dirty recompute of H = 5 (recompute lazily on the first query after `dirtyRing`; also recompute the forecast H when a storm exists).
- [ ] `damageReport(state, storm)`: `bill` = Σ `(1 − hp) × row.cost × .6` over damaged buildings + `towerTopple` + levee repairs (`$5k` per tile < 100); `tarps` = damaged building count; `held/overtopped/breached` from `hydro.stormLog()`; `flooded` = `hydro.floodedBuildings()`; `choices` = `state.setPiece.choices`; the insurance payout is economy's (it listens to `storm:report`).

## 5. Edge cases and invariants

- `buildings[]` may contain `null`; every iterator skips nulls; `id === index` always; never splice.
- `hp ∈ [0,1]`, `built ∈ [0,1]`, `sunk ≥ 0`; `tier ≤ tiers.length`.
- `owner` entries always point to a non-null building; `remove` clears them first.
- `canPlace` on the title world / before terrain gen: arrays are zeros → every land rule fails gracefully.
- Never throw across the boundary: every action returns `{ok:false, reason}`.
- `economy.charge` may refuse (loan limit): place must not partially apply — validate → charge → apply.
- The Founders' reserved footprint is enforced here (see step 5).
- Set pieces: `tick` still runs but `flags.newDay` is false → no construction progress during a landfall (calendar frozen); wind pulses apply immediately in the tick they were received.
- Load / new game: `reset(state, fresh)` rebuilds coverage (`recomputeCoverage` once), auras, ring cache, `connected` mask, undo cleared, `gatorClosed` scratch — the same for both `fresh` values.
- Never `Infinity`: `closedUntil`, `builtDay`, `upgradeDoneDay`, `boardedUntil`, `stockedDay` use `-1` (§10.3).
- Headless `findSpot` calls `canPlace` up to ~6,500 times: keep `canPlace` ≤ 0.05 ms for the common red cases (check bounds/terrain before access BFS lookups; the `connected` mask makes access O(edge tiles)).
- `place` during `economy.suppressCoverage`: icons computed, penalty off (`effective` returns 1).

## 6. selfTest() requirements

Private `BSU.newState(21)` with a synthetic map: a 12×12 block at 6 ft (crown) with a 7-tile "highway" `surface 2` touching a 3×3 "founders" footprint you place with `instant`; a 4×4 cove at 1.8 ft with a 2.2 lip; marsh around; a bayou strip. Stub `economy` (`canAfford → true`, `charge → true`), `progress.unlocked → true` / `unlockReason → ''`, `hydro` (`footprintDepth → 0`, `markCanal/markPond/markLeveeChange` no-ops that set flags, `stormLog`), `terrain` (`setSurface/setElev/touch/rewalk/plantVeg` minimal), `wildlife.onCampus → []` through `M._deps`, and replace `M._deps.emit` with a recorder for the duration (restored in `finally`) — `building:*`/`power:*`/`ring:changed` must never reach the live bus (§10.6). Assertions with `BSU.assert` (the harness sets `BSU.SELFTEST`).

1. `canPlace('dorm')` on the crown next to the highway → `ok`, `color:'green'`, `cost === 700000`; on the crown without any path within reach → `reason:'Needs a path'`; on the cove (1.8 ft Wet) → `ok`, `terrainMod === .2`, `cost === 840000`; on marsh → `needsPilings`, `pilingsCost === 280000`, `color:'yellow'`; on a sloped site (span 2 ft) → `needsGrading`, `gradingCost === 90000`; overlapping the founders' footprint → `'Occupied'`; `'founders_hall'` anywhere but the reserved origin → refused.

6. Ring fill on a synthetic 10×10 ring of levee tiles (crest 6 on 2-ft land) around a 4-ft interior with water outside: at H = 5 the interior is unreached (`ringClosed` true for a core building inside); remove one tile → `gaps(5)` has one gap of len ≥ 1; set the tile back with `integrity 40` (crest halved → head 5) → reached (`≤ H`); a FLOODGATE tile (canal + levee, integrity 100) → unreached; the same tile JAMMED → reached (T7 static half).

## 8. Performance budget

- `tick` ≤ 0.3 ms typical (daily loop over ≤ 400 buildings); `recomputeCoverage` ≤ 2 ms (providers × consumers ≤ 60 × 400 with an early distance reject); ring BFS ≤ 3 ms (one `Uint8Array` visited + a `Uint16Array` queue; cached per H); auras ≤ 3 ms (radius loops over footprint tiles, only when dirty); `canPlace` ≤ 0.05 ms for red cases, ≤ 0.3 ms with the ring scratch fill (levee drags: the fill is re-run per pointermove → ui throttles to every 50 ms; keep a scratch `Uint8Array` for the modified crests).
- No per-tick allocation in the daily loops (scratch arrays in the closure).
